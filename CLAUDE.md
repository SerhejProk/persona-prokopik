# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это за репозиторий

`D:\Work` содержит один проект — `Persona/`: статичная одностраничная визитка Сергея Прокопика (директор ООО «ПНД Групп»). Это чистый HTML/CSS без сборки, без зависимостей, без тестов и без системы контроля версий (не git-репозиторий).

## Команды

Сборки, линтера и тестов нет. Чтобы посмотреть страницу — просто открыть `.html`-файл в браузере (двойной клик или `Persona/index.html` в браузере). Для локального сервера, если он понадобится:

```powershell
cd Persona
python -m http.server 8000
```

## Структура и архитектура

- `Persona/index.html` и `Persona/index-v2.html` — два независимых, самодостаточных варианта визитки (весь CSS инлайнится в `<style>` внутри каждого файла, общих стилей/скриптов нет). `index-v2.html` — более новая версия с sticky-навигацией и другой цветовой схемой (светлая, "paper", vs тёмная "amber/gold" в `index.html`). При правке контента (текст, факты, карточки) изменения обычно нужно вносить в оба файла — они дублируют один и тот же текст с разной вёрсткой/стилями.
- Оба HTML-файла — самостоятельный источник истины по итоговому тексту на странице; `.md`-файлы в корне `Persona/` — это исходники/черновики того же контента для более удобного редактирования текста без разметки:
  - `profile.md` — развёрнутое резюме от первого лица.
  - `я.md` — краткая версия "обо мне" с списком увлечений.
  - `проекты.md` — раздел "чем занимаюсь" (производство/продажи).
  - `факты.md` — истории для секции "Интересные факты" на странице.
  
  При изменении текста визитки обычно нужно синхронизировать соответствующий `.md`-файл и оба `index*.html`.
- `Persona/images/` — фотографии, используемые в HTML (`portrait.jpg`, `background.jpg`, `production.jpg`, `meeting.jpg`, `gears.jfif`, `dog.jpg` и др.) плюс `CREDITS.md` с указанием авторов/лицензий (Openverse, CC BY / CC BY-SA). **Важно:** список файлов в `CREDITS.md` (jail.jpg, mask.jpg, safe.jpg, number.jpg, car.jpg) не совпадает с реально используемыми в HTML изображениями — файл, судя по всему, устарел и требует актуализации при следующей правке лицензий.
